# 🧾 เปิดระบบตรวจสอบสลิปอัตโนมัติ (EasySlip)

ปกติเมื่อแขกแนบสลิปโอนเงิน ระบบจะเก็บรูปสลิปไว้ให้บ่าวสาว **ตรวจเอง** ในหน้า "ซองออนไลน์"
ถ้าอยากให้ระบบ **อ่านสลิปและยืนยันจำนวนเงินอัตโนมัติ** ให้เชื่อมบริการ **EasySlip**

> EasySlip เป็นบริการของไทยที่อ่านสลิปโอนเงิน/พร้อมเพย์ แล้วบอกจำนวนเงิน เลขอ้างอิง ผู้โอน-ผู้รับ ให้อัตโนมัติ

---

## เมื่อไหร่ควรเปิด?
- งานใหญ่ แขกเยอะ ไม่อยากมานั่งกดยืนยันสลิปทีละใบ
- อยากได้ยอด "ตรวจสอบแล้ว" ที่เชื่อถือได้ในหน้าสรุป

ถ้างานเล็ก ข้ามได้ — ยืนยันเองในแดชบอร์ดก็เพียงพอ

---

## ขั้นที่ 1: สมัคร EasySlip และเอา API Token

1. เข้าเว็บ https://easyslip.com
2. สมัครสมาชิก / เข้าสู่ระบบ
3. เลือกแพ็กเกจ (มีเครดิตทดลอง/แพ็กเกจตามปริมาณการตรวจ)
4. ไปหน้า **API / Developer** เพื่อคัดลอก **API Token** ของคุณ

> ราคาและรายละเอียดแพ็กเกจให้ดูจากเว็บ EasySlip โดยตรง (มีการคิดค่าบริการตามจำนวนสลิปที่ตรวจ)

---

## ขั้นที่ 2: ใส่ค่าในไฟล์ `.env`

เปิดไฟล์ `.env` (ไฟล์ตั้งค่าที่อยู่ในโฟลเดอร์โปรเจกต์) แล้วแก้ 2 บรรทัดนี้:

```env
SLIP_VERIFY_PROVIDER="easyslip"
EASYSLIP_API_TOKEN="วาง-token-ที่ได้จาก-easyslip-ตรงนี้"
```

บันทึกไฟล์ แล้ว **รีสตาร์ทเว็บ** (กด `Ctrl+C` ในหน้าต่างที่รัน แล้วรัน `npm run dev` หรือ `npm run start` ใหม่)

> 🔐 ค่าเหล่านี้เป็นความลับระดับเซิร์ฟเวอร์ ตั้งครั้งเดียวใช้กับทุกงาน (ไม่ต้องใส่รายงาน)

---

## ขั้นที่ 3: ทดสอบ

1. เปิดหน้าแขก → กด "ใส่ซองออนไลน์" → กรอกจำนวนเงิน + แนบรูปสลิปจริง → ส่ง
2. เข้า Dashboard → เมนู **ซองออนไลน์**
3. สถานะควรขึ้นเป็น **✅ ตรวจสอบแล้ว** และจำนวนเงินจะถูกดึงจากสลิปจริง

### สถานะที่เป็นไปได้
| สถานะ | ความหมาย |
| --- | --- |
| ✅ ตรวจสอบแล้ว | EasySlip อ่านสลิปสำเร็จ ยืนยันยอดแล้ว |
| ⏳ รอตรวจสอบ | ยังไม่ได้เปิด EasySlip หรืออ่านไม่ได้ → กดยืนยันเองได้ |
| ⚠️ สลิปซ้ำ | สลิปนี้เคยถูกใช้แล้ว (กันคนแนบสลิปเดิมซ้ำ) |
| ❌ ไม่ผ่าน | อ่านสลิปไม่สำเร็จ (รูปเบลอ/ไม่ใช่สลิป) |

> เมื่อเปิด EasySlip ระบบจะเชื่อจำนวนเงินจากสลิปจริง แทนที่ตัวเลขที่แขกพิมพ์เอง — ทำให้ยอดสรุปแม่นยำขึ้น

---

## หมายเหตุด้านความปลอดภัย
- อย่าแชร์ `EASYSLIP_API_TOKEN` กับใคร และอย่า commit ไฟล์ `.env` ขึ้น git (โปรเจกต์ตั้ง `.gitignore` ป้องกันให้แล้ว)
- ถ้าเอาขึ้นเซิร์ฟเวอร์จริง ให้ตั้งค่าเหล่านี้ผ่าน "Environment Variables" ของผู้ให้บริการ (ดู [04-deploy.md](./04-deploy.md))
