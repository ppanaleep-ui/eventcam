# 🔔 เชื่อม LINE ให้แจ้งเตือนเข้ามือถือบ่าวสาว

เมื่อเชื่อมแล้ว ทุกครั้งที่แขกส่งคำอวยพรหรือใส่ซองออนไลน์ บ่าวสาวจะได้ข้อความแจ้งเตือนเข้า LINE ทันที

> ระบบใช้ **LINE Messaging API** (ผ่าน LINE Official Account) — ฟรีสำหรับการใช้งานทั่วไป
> (หมายเหตุ: LINE Notify แบบเดิมถูกปิดบริการไปแล้ว เราจึงใช้ Messaging API แทน)

---

## ภาพรวมสิ่งที่ต้องได้มา 2 อย่าง
1. **Channel access token** — เหมือนกุญแจให้ระบบส่งข้อความแทน LINE OA ของคุณ
2. **ปลายทาง (userId หรือ groupId)** — ว่าจะให้ส่งเข้าใคร/กลุ่มไหน

---

## ขั้นที่ 1: สร้าง LINE Official Account + Channel

1. เข้า **LINE Developers Console**: https://developers.line.biz/console/
2. ล็อกอินด้วยบัญชี LINE ของคุณ
3. กด **Create a new provider** → ตั้งชื่ออะไรก็ได้ (เช่น "งานแต่งเรา") → Create
4. ในหน้า provider กด **Create a new channel** → เลือก **Messaging API**
5. กรอกข้อมูลที่จำเป็น (ชื่อ, หมวดหมู่ ฯลฯ) แล้วสร้าง

---

## ขั้นที่ 2: เอา Channel access token

1. เข้าไปในช่อง (channel) ที่เพิ่งสร้าง
2. ไปแท็บ **Messaging API**
3. เลื่อนลงหา **Channel access token (long-lived)** → กด **Issue**
4. คัดลอกข้อความยาว ๆ ที่ได้ **เก็บไว้** (นี่คือค่าที่ 1)

---

## ขั้นที่ 3: หา "ปลายทาง" (จะให้ส่งเข้าใคร)

วิธีที่ง่ายที่สุดคือส่งเข้า **แชทส่วนตัวของบ่าวสาวเอง**:

1. ในแท็บ **Messaging API** จะมี **QR code** ของ LINE OA → ให้บ่าวสาว **สแกนเพื่อเพิ่มเป็นเพื่อน**
2. ตอนนี้ยังต้องหา `userId` ของคนที่จะรับ ซึ่งดูจากหน้าจอตรง ๆ ไม่ได้ มี 2 ทางเลือก:

   **ทางเลือก A — ส่งเข้ากลุ่ม (แนะนำ ง่ายสุด):**
   - สร้างกลุ่ม LINE เล็ก ๆ (เช่น "แจ้งเตือนงานแต่ง") แล้วเชิญ LINE OA เข้ากลุ่ม
   - ต้องใช้ `groupId` ซึ่งได้จาก webhook (ดูทางเลือก B วิธีจับค่า)

   **ทางเลือก B — จับ userId/groupId ด้วย webhook:**
   - ในแท็บ Messaging API เปิด **Use webhook** = ON
   - ตั้ง Webhook URL ชั่วคราวเป็นบริการที่ดูค่าที่ส่งเข้ามาได้ เช่น https://webhook.site (คัดลอก URL ที่เว็บนั้นให้มา ไปวางเป็น Webhook URL)
   - ทักข้อความหา LINE OA (หรือพิมพ์ในกลุ่ม) 1 ครั้ง
   - กลับไปดูที่ webhook.site จะเห็น JSON มีค่า `"userId": "Uxxxx..."` (หรือ `"groupId": "Cxxxx..."`) — **นั่นคือค่าที่ 2**

> 📝 userId ขึ้นต้นด้วย `U...` / groupId ขึ้นต้นด้วย `C...`

---

## ขั้นที่ 4: ใส่ค่าลงในระบบ PhotoWish

1. ล็อกอินเข้า Dashboard → เลือกงาน → เมนู **ตั้งค่า**
2. เลื่อนลงหาหัวข้อ **💬 แจ้งเตือนเข้า LINE**
3. วาง **Channel access token** (ค่าที่ 1) ลงช่องแรก
4. วาง **userId / groupId** (ค่าที่ 2) ลงช่องที่สอง
5. กด **บันทึกการตั้งค่า**

---

## ขั้นที่ 5: ทดสอบ

1. เปิดหน้าแขก `/e/<slug>` → ส่งคำอวยพรทดสอบ 1 อัน
2. ภายในไม่กี่วินาที ควรมีข้อความเด้งเข้า LINE ปลายทาง 🎉

### ถ้าไม่มีข้อความเข้า ลองเช็ค:
- token ถูกต้องไหม (คัดลอกครบ ไม่มีช่องว่างหน้า-หลัง)
- ปลายทางเพิ่ม LINE OA เป็นเพื่อนแล้ว / OA อยู่ในกลุ่มแล้วหรือยัง
- ถ้าใช้กลุ่ม ต้องเป็น `groupId` ไม่ใช่ `userId`
- ดู log ในหน้าต่าง Terminal ที่รันเว็บ จะมีบรรทัดขึ้นต้น `[line]` บอกสาเหตุ

> ระบบออกแบบให้ **ถ้า LINE ส่งไม่สำเร็จ จะไม่ทำให้แขกส่งคำอวยพรไม่ได้** — การแจ้งเตือนเป็นส่วนเสริม ไม่บล็อกการใช้งานหลัก
