# 📘 คู่มือเริ่มต้น (สำหรับคนที่ไม่เคยทำมาก่อน)

คู่มือนี้จะพาคุณรัน PhotoWish บนคอมพิวเตอร์ของคุณเองแบบทีละขั้น ไม่ต้องมีพื้นฐานโปรแกรมมิ่งมาก่อน

---

## สิ่งที่ต้องมี (ติดตั้งครั้งเดียว)

### 1. Node.js (โปรแกรมที่ใช้รันเว็บนี้)
1. เข้าเว็บ https://nodejs.org
2. ดาวน์โหลดปุ่มที่เขียนว่า **LTS** (เวอร์ชันแนะนำ) — ต้องเป็นเวอร์ชัน 18 ขึ้นไป (โปรเจกต์นี้ทดสอบบน 22)
3. เปิดไฟล์ที่โหลดมา กด Next ไปเรื่อย ๆ จนจบ
4. ตรวจว่าติดตั้งสำเร็จ: เปิดโปรแกรม **Terminal** (Mac) หรือ **Command Prompt / PowerShell** (Windows) แล้วพิมพ์:
   ```bash
   node --version
   ```
   ถ้าขึ้นตัวเลขเช่น `v22.x.x` แปลว่าใช้ได้แล้ว ✅

> 💡 **Terminal คืออะไร?** คือหน้าต่างสีดำ ๆ ที่เราพิมพ์คำสั่งให้คอมทำงาน
> - **Mac:** กด `Cmd + Space` พิมพ์ "Terminal" แล้ว Enter
> - **Windows:** กดปุ่ม Start พิมพ์ "PowerShell" แล้ว Enter

---

## รันโปรเจกต์ครั้งแรก (ทำตามทีละบรรทัด)

เปิด Terminal แล้วพิมพ์ทีละคำสั่ง (พิมพ์เสร็จกด Enter รอให้เสร็จก่อนค่อยพิมพ์บรรทัดถัดไป)

### 1) เข้าไปในโฟลเดอร์โปรเจกต์
```bash
cd path/to/eventcam
```
> แทน `path/to/eventcam` ด้วยที่อยู่จริงของโฟลเดอร์ เช่น `cd Documents/eventcam`

### 2) ติดตั้งส่วนประกอบที่จำเป็น (รอสักครู่ ครั้งแรกอาจนาน 1–2 นาที)
```bash
npm install
```

### 3) สร้างไฟล์ตั้งค่า `.env`
คัดลอกไฟล์ตัวอย่างมาเป็นไฟล์จริง:
```bash
cp .env.example .env
```
> Windows PowerShell ใช้: `copy .env.example .env`

จากนั้น **สร้างรหัสลับ** สำหรับความปลอดภัย (เอาไว้เข้ารหัสการล็อกอิน):
```bash
npm run gen:secret
```
จะได้ข้อความยาว ๆ เช่น `a1b2c3d4...` — เปิดไฟล์ `.env` ด้วยโปรแกรมแก้ข้อความ (เช่น Notepad / TextEdit) แล้วเอาค่านั้นไปวางแทนที่บรรทัด:
```
SESSION_SECRET="dev-only-insecure-secret-change-me-in-production-00000000"
```
ให้กลายเป็น:
```
SESSION_SECRET="a1b2c3d4...(ค่าที่ได้)"
```

### 4) สร้างฐานข้อมูล
```bash
npm run db:migrate
```
> ถ้ามันถามชื่อ migration ให้พิมพ์อะไรก็ได้ เช่น `init` แล้ว Enter

### 5) (ไม่บังคับ) ใส่ข้อมูลตัวอย่างไว้ลองเล่น
```bash
npm run db:seed
```
มันจะพิมพ์บัญชีทดลองออกมา:
```
Login: demo@photowish.app / password123
Guest page: /e/xxxxxxxx
Slideshow:  /e/xxxxxxxx/slideshow
```
> จดลิงก์ `/e/xxxxxxxx` ไว้ เดี๋ยวได้ใช้

### 6) เปิดเว็บ!
```bash
npm run dev
```
รอจนเห็นข้อความ `Ready` แล้วเปิดเบราว์เซอร์ไปที่ 👉 **http://localhost:3000**

> ⚠️ อย่าปิดหน้าต่าง Terminal ระหว่างใช้งาน ถ้าปิดเว็บจะดับ (จะหยุดเว็บให้กด `Ctrl + C` ใน Terminal)

## ลองใช้งานให้ครบทั้ง 3 ฝั่ง

### 👰 ฝั่งบ่าวสาว (Dashboard)
1. ไปที่ http://localhost:3000/login
2. ล็อกอินด้วย `demo@photowish.app` / `password123`
3. คลิกเข้างานที่มีอยู่ จะเห็นเมนู: ภาพรวม / คำอวยพร / ซองออนไลน์ / QR & ลิงก์ / หนังสือที่ระลึก / ตั้งค่า

### 💌 ฝั่งแขก (มือถือ)
1. เปิดลิงก์ `http://localhost:3000/e/xxxxxxxx` (ใช้ slug จากขั้นตอน seed)
2. กด "ส่งรูป & คำอวยพร" → ใส่ชื่อ เลือกรูป พิมพ์ข้อความ → ส่ง
3. ลองกด "ใส่ซองออนไลน์" → จะเห็น QR PromptPay และช่องแนบสลิป

### 🖥️ สไลด์โชว์ (จอหน้างาน)
1. เปิด `http://localhost:3000/e/xxxxxxxx/slideshow` ในอีกแท็บ
2. กลับไปส่งคำอวยพรใหม่จากฝั่งแขก → คำอวยพรจะ **เด้งขึ้นสไลด์โชว์ทันที** พร้อมป้าย "คำอวยพรใหม่!"

> ✨ นี่คือหัวใจของระบบ: ทุกอย่างอัปเดตแบบเรียลไทม์

## ปัญหาที่พบบ่อย & วิธีแก้

| อาการ | สาเหตุ / วิธีแก้ |
| --- | --- |
| `command not found: npm` | ยังไม่ได้ติดตั้ง Node.js หรือยังไม่ปิด-เปิด Terminal ใหม่หลังติดตั้ง |
| `port 3000 is already in use` | มีเว็บอื่นใช้พอร์ตนี้อยู่ ปิดโปรแกรมนั้น หรือรันด้วยพอร์ตอื่น: `npm run dev -- -p 3001` |
| หน้าเว็บขึ้น error เรื่อง `SESSION_SECRET` | ยังไม่ได้ใส่ค่า SESSION_SECRET ใน `.env` (ดูขั้นตอน 3) |
| รูปที่อัปโหลดไม่ขึ้น | ปกติ — รูปเก็บในโฟลเดอร์ `storage/` และเสิร์ฟผ่าน `/api/files/...` ให้แล้ว ลองรีเฟรชหน้า |
| อยากล้างข้อมูลเริ่มใหม่ | ลบไฟล์ `prisma/dev.db` แล้วรัน `npm run db:migrate` และ `npm run db:seed` ใหม่ |
| แก้โค้ดแล้วไม่อัปเดต | โหมด `npm run dev` จะรีเฟรชอัตโนมัติ ถ้าไม่ ให้กด `Ctrl+C` แล้วรัน `npm run dev` ใหม่ |
