# ✅ เช็คลิสต์วันงาน

พิมพ์หน้านี้เก็บไว้ หรือทำตามทีละข้อ เพื่อให้วันงานราบรื่น

---

## 🗓️ 1–2 สัปดาห์ก่อนงาน

- [ ] Deploy เว็บขึ้นออนไลน์เรียบร้อย (ดู [04-deploy.md](./04-deploy.md)) และเข้าจากมือถือได้จริง
- [ ] เข้า Dashboard → **ตั้งค่า** กรอกให้ครบ:
  - [ ] ชื่อเจ้าสาว–เจ้าบ่าว, วันจัดงาน, สถานที่
  - [ ] ข้อความต้อนรับแขก
  - [ ] อัปโหลด **รูปหน้าปก**
  - [ ] อัปโหลด **รูป Pre-wedding** (จะขึ้นสลับกับคำอวยพรบนสไลด์โชว์)
- [ ] ถ้าจะรับซองออนไลน์: เปิด "เปิดรับซองออนไลน์" + ใส่ **PromptPay** (เบอร์/เลขบัตร) และชื่อบัญชี
- [ ] ถ้าจะรับแจ้งเตือน: เชื่อม **LINE** (ดู [02-line-notify.md](./02-line-notify.md)) และทดสอบให้เข้าจริง
- [ ] ถ้าจะตรวจสลิปอัตโนมัติ: เปิด **EasySlip** (ดู [03-easyslip.md](./03-easyslip.md))
- [ ] ตัดสินใจเรื่อง **โหมดกลั่นกรอง** (ตรวจคำอวยพรก่อนขึ้นจอ):
  - เปิด = ปลอดภัยกว่า แต่ต้องมีคนคอยกดอนุมัติหน้างาน
  - ปิด = คำอวยพรขึ้นจอทันที (เหมาะกับงานที่ไว้ใจแขก)

---

## 🖨️ เตรียมสื่อหน้างาน

- [ ] เข้าเมนู **QR & ลิงก์** → กด **ดาวน์โหลด QR** → ส่งให้ร้านทำป้าย/สแตนดี้
  - วาง QR ที่ **โต๊ะลงทะเบียน** และจุดที่แขกเห็นง่าย (โต๊ะอาหาร, ทางเข้า)
  - ใส่ข้อความชวนเชิญ เช่น "สแกนส่งรูป & คำอวยพรให้บ่าวสาว 💌"
- [ ] คัดลอก **ลิงก์อวยพร** ส่งให้เพื่อน/ญาติที่มาร่วมงานไม่ได้
- [ ] คัดลอก **ลิงก์สไลด์โชว์** ส่งให้ทีมโรงแรม/ช่างภาพที่ดูแลจอ

---

## 🖥️ ตั้งค่าสไลด์โชว์ (ทำก่อนแขกเข้า)

- [ ] เปิดลิงก์สไลด์โชว์ `/e/<slug>/slideshow` บนเครื่องที่ต่อโปรเจกเตอร์/จอใหญ่
- [ ] กด **F11** (หรือปุ่มเต็มจอของเบราว์เซอร์) ให้เต็มจอ
- [ ] ปิด **โหมด Sleep / Screen saver** ของเครื่อง ไม่ให้จอดับกลางงาน
- [ ] เช็คว่าเครื่องนั้นต่อ **อินเทอร์เน็ตเสถียร** (สไลด์โชว์ต้องออนไลน์เพื่อรับคำอวยพรสด)
- [ ] ทดสอบ: ส่งคำอวยพร 1 อันจากมือถือ → ต้องเด้งขึ้นจอภายในไม่กี่วินาที

---

## 🎉 ระหว่างงาน

- [ ] มีคนคอยดู LINE แจ้งเตือน (ถ้าเปิดโหมดกลั่นกรอง ต้องคอยกด **อนุมัติ** ในเมนูคำอวยพร)
- [ ] เช็คหน้า **ซองออนไลน์** เป็นระยะ ดูยอดรวม/ตรวจสลิป
- [ ] ถ้าจอค้าง: รีเฟรชหน้าเบราว์เซอร์ของสไลด์โชว์ (ข้อมูลไม่หาย)

---

## 📦 หลังงาน

- [ ] เข้าเมนู **คำอวยพร** ตรวจ/ซ่อนอันที่ไม่ต้องการ (เช่น ทดสอบ/สแปม)
- [ ] เข้าเมนู **ซองออนไลน์** → ตรวจให้ครบ ดูยอดสรุปสุดท้าย
- [ ] อัปโหลด **รูปบรรยากาศในงาน** เพิ่มในเมนูตั้งค่า (ประเภท "บรรยากาศงาน")
- [ ] เข้าเมนู **หนังสือที่ระลึก**:
  - กด **ดาวน์โหลดข้อมูล (JSON)** ส่งให้ทีมทำเล่มจริง
  - หรือกด **พิมพ์ / บันทึกเป็น PDF** เพื่อดูตัวอย่างเลย์เอาต์
- [ ] อย่าเพิ่งปิดเซิร์ฟเวอร์จนกว่าจะดึงข้อมูลครบ (สำรองไฟล์ฐานข้อมูล + โฟลเดอร์รูปไว้ด้วย)

## 🆘 แผนสำรองฉุกเฉิน

| ปัญหาเฉพาะหน้า | ทำยังไง |
| --- | --- |
| เน็ตหน้างานล่ม | สไลด์โชว์จะค้างชั่วคราว พอเน็ตกลับมารีเฟรชหน้าได้เลย ข้อมูลที่แขกส่งไม่หาย |
| จอสไลด์โชว์ดับ | เปิดลิงก์สไลด์โชว์ใหม่ในเบราว์เซอร์ กด F11 เต็มจอ |
| แขกสแกน QR ไม่ได้ | ให้พิมพ์ลิงก์สั้น ๆ หรือเตรียม QR สำรองไว้อีกจุด |
| อยากหยุดรับชั่วคราว | ปิด "เปิดรับซองออนไลน์" ในตั้งค่า (คำอวยพรยังรับได้) |
